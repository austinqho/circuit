**Claim under test:** backend telemetry works by default for ESM (`"type": "module"`) Express apps started with `node --import producttrace/backend/register server.js`. The entrypoint registers the OTel ESM loader hook through `module.register()` and starts telemetry with the default adapters `http,express,mongodb`. CommonJS behaves as before. When the hook cannot be registered, the process prints a clear warning and server spans carry a capture-limit attribute.

**Verdict: MERGE WITH CHANGES.** The changes are documentation only (listed at the end). The code does what the claim says, and I verified it end to end from the packed tarball.

## Residual risks

1. **The primary README contradicts the new default** (see the last table row). This is the most user-visible gap.
2. **The fallback line resolves `@opentelemetry/instrumentation/hook.mjs` from the app's cwd.** That works with npm's hoisted layout (verified here). Under pnpm or another strict layout, the app cannot resolve the transitive dependency, so the printed fallback would fail. Consider exposing a `producttrace/backend/hook` re-export, or printing the absolute resolved path.
3. **`--import producttrace/backend/register` resolves from cwd.** Starting node from a directory that cannot resolve `producttrace` (for example a monorepo root) fails with `ERR_MODULE_NOT_FOUND`. This is standard Node behaviour, but it is not documented.
4. **`loaderAlreadyPresent()` trusts any argument ending in `instrumentation/hook.mjs` or `import-in-the-middle/hook.mjs`.** A different iitm copy passed by the operator is accepted as equivalent. It worked here because npm deduped to one copy.
5. **DEP0205 is consumed for the whole process** (item 5c). This is cosmetic.
6. **Shipping is one un-batched HTTP POST per relevant span, fire-and-forget.** Spans still in flight at exit are lost, the same as the deleted preload. That is fine for dev but not for load.
7. **The G2/G5 harness path (`build-fresh-repo.mjs` → anything-llm) was not exercised** in this grade. anything-llm now also gets the ESM hook where it had none before. Re-run G2 once before relying on those numbers.
8. Only Node 26.7 was exercised. The real-old-Node fallback (≤ 20.5, where `--experimental-loader` semantics differ) was simulated by deleting `module.register`, not run on an actual old Node.
