# Raw evidence files over GitHub's size limit

Seven raw `records.jsonl` files from the 2026-09-22 M1 cycles (249–472 MB each) exceed GitHub's 100 MB per-file limit. In the published history they are replaced by gzipped copies (`*.jsonl.gz`, lossless) next to where the raw file lived; `RAW-SHA256-large-files.txt` lists each raw file's sha256 and row count so a decompressed copy can be checked against the grades that cite them. Blobs larger than 50 MB were stripped from the unpublished local history before the first push, one PostHog client token in a captured HTML snippet was redacted, and three OpenAI-internal documents were moved to an unpublished `docs/internal/` folder; nothing else was rewritten. Commit hashes cited in handoffs and gate docs are from the pre-rewrite local history; tags are authoritative.
