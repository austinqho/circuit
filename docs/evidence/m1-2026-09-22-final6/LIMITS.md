# Limits

- Headless Chromium only; no visible browser or GUI application.
- A drive unit is the first depth-zero registered first-party entry handler per dispatched action plus event type. Deeper frames and later depth-zero React work remain spine evidence and receive no action outcome.
- A static unit is `rendered_not_driven` when a fiber walk saw it but no dispatch executed it as an entry handler; `not_encountered` means neither render nor entry execution occurred.
- Backend/database outcomes require exact trace-parent joins in the retained span evidence; database reads can reach the backend but never satisfy `reached_db`.
- `correct_stop` requires a DOM mutation receipt in the same action; an action without one is `stop_with_reason: no_effect_witnessed`.
- Chat completions came from a deterministic local HTTP fixture; the runtime path made no model call.
- The repository suite passed 531/532 tests. The isolated pre-existing `react-context-ref-semantics` assertion still fails with `'a' !== 'b'`; the new entry-handler regression test passes.
