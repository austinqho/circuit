# Limits

- Headless Chromium was used only for the requested login plus eight-flow scripted verification.
- The pattern crawler was not run. No coverage percentage is claimed.
- Terminal rooting uses captured continuation ancestry; render- and effect-invoked frames are ineligible, while non-selected frames remain spine evidence.
- Database success requires an exactly joined write operation; reads do not satisfy the gate.
- This verification used the deterministic local OpenAI-compatible fixture, so it made no model call. The separate live build is configured to use the real key from the fixture `.env`.
