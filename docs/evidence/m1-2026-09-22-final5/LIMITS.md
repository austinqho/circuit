# Limits

- Headless Chromium only; no visible browser or GUI application.
- Static units are `not_encountered` only when no prop-matched dispatch and no registered handler entry in a dispatched action lineage encountered them; attempted but unavailable elements retain explicit reachability reasons.
- Backend/database outcomes require exact trace-parent joins in the retained span evidence; database reads can reach the backend but never satisfy `reached_db`.
- `correct_stop` requires a DOM mutation receipt in the same action; an action without one is `stop_with_reason: no_effect_witnessed`.
- Chat completions came from a deterministic local HTTP fixture; the runtime path made no model call.
